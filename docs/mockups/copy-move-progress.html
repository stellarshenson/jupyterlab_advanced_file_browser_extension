Copy and move progress

The decided progress dialog: the Midnight Commander layout with Cancel and Hide. A copy or move still running 1 s after it starts opens it; Hide moves it to one status bar item, and a click on that item opens the dialog again, or the operations menu when several run. A second copy or move runs in parallel and hides the dialog shown before. Each menu row shows the file count and how long ago the operation started. The sample is 3 items: one 2.00 GiB file, then a folder of 19 998 small files, then one note; it plays in a loop. A move on one volume is a rename and ends before the dialog opens. The mocked lab uses the JupyterLab Light and Dark theme colours.
